## pr#1732

此PR新增了 illegal_vtype 配置项，用来控制向量指令遇到非法或保留 vtype 时是设置 vill、抛非法指令异常，还是以 fatal 方式终止模型执行。
修改了以下文件：
- `config/config.json.in`：在 `extensions.V` 下新增 `illegal_vtype` 配置项，并用注释说明非法或保留 `vtype` 可选择设置 `vill`、抛非法指令或 fatal 终止三种行为。
- `model/core/platform_config.sail`：新增 `IllegalVtypeReservedBehavior` 枚举，并把 `config extensions.V.illegal_vtype` 读入为模型内部使用的 `illegal_vtype_reserved_behavior` 策略变量。
- `model/extensions/V/vext_vset_insts.sail`：重构 `vsetvl/vsetvli/vsetivli` 的非法 `vtype` 处理逻辑，使其根据配置选择返回 `Illegal_Instruction()`、触发 `reserved_behavior` fatal，或保持原先设置 `vtype.vill`、清零 `vl/vstart` 并写回 `rd` 的行为。

## swid 扩展

swid是riscv-worlds扩展中的一个子扩展， 为在sail-riscv中实现其语义， 做出了以下修改:

- `model/extensions/Smwid/smwid.sail`：新增 Smwid/Worlds 的核心模型，实现 `mwid` CSR、WID 提取与合法化、授权 WID 列表检查、世界内存区域匹配、按读/写/执行/PTW 权限判定访问，以及未授权访问时返回 access fault 或 fatal error 的策略。
- `model/core/extensions.sail`：把 `Smwid` 注册为模型可识别的扩展，加入扩展名映射、配置开关读取逻辑，并声明它在启用时依赖 `Zicsr`。
- `config/config.json.in`：新增 `extensions.Smwid` 配置项和 `platform.worlds` 配置块，用于配置是否支持 Smwid、世界数量、平台默认 WID、授权 WID mask、`mwid` reset 锁定位，以及按物理地址划分的世界访问权限区域。
- `model/postlude/validate_config.sail`：新增 Smwid/Worlds 配置校验，检查 `Smwid` 对 `Zicsr` 的依赖、`nworlds` 范围、`pmwid` 与 `pmwidlist` 合法性、世界区域大小非零、不回绕、不重叠递增，以及各权限 mask 不设置超出 `nworlds` 的位。
- `model/sys/sys_control.sail`：在系统 reset 流程中调用 `reset_smwid()`，确保 `mwid` 按配置初始化并通过 CSR callback 暴露初始值。
- `model/sys/mem.sail`：把当前 WID 接入物理内存访问路径，在 PMP/PMA 检查前执行 Smwid 访问控制，并把 WID 传递给 RAM、MMIO、内存访问 callback 和异常 callback。
- `model/core/phys_mem_interface.sail`：扩展 RAM 读写接口以接收 WID，并把多 bit WID 压缩成 Sail concurrency v1 可承载的布尔 transaction tag，同时保留完整 WID 经由显式 callback/MMIO 路径传播。
- `model/sys/platform.sail`：扩展 CLINT/HTIF 等 MMIO 读写接口以接收 WID，并在相关平台 trace 日志中追加 WID 信息，保证平台级访问也能带上世界身份。
- `model/sys/vmem.sail`：在地址翻译过程中计算当前访问的 WID，并把它纳入 TLB 查找和新增条目的参数，使虚实地址翻译缓存按世界身份区分。
- `model/sys/vmem_tlb.sail`：在 `TLB_Entry` 中新增 `wid` 字段，并要求 TLB hit 同时匹配 ASID/VPN 和 WID，避免不同 world 复用同一条翻译缓存。
- `model/core/callbacks.sail`：扩展内存读、写和异常 callback 的 Sail extern 签名，使 callback 能接收并转发当前 WID。
- `c_emulator/*callbacks*`：同步更新 C++ emulator 的 callback 接口、默认实现、日志实现和 RVFI 实现，在内存读写/异常 callback 中携带 WID，并在 trace 输出里打印 `wid=` 信息。
